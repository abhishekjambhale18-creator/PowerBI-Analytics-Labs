### 📌 Project Overview

This repository contains hands-on **Power BI labs** created as part of my Data Analytics learning path.  
Current focus is on proper data modeling (star schema, dimension & fact tables, relationships, and bridge tables) which is the most important foundation before building final dashboards.

---

### 📚 Labs Included

| Lab | File | Focus |
| --- | --- | --- |
| Lab 1 | `PowerBI1.pbix` | Getting started – data import & basic setup |
| Lab 2 | `PowerBI2.pbix` | Sales Star Schema (Customer, Product, Date, Region, Sales) |
| Lab 3 | `PowerBI3.pbix` | HR Analytics Model (Fact + Dimensions + Bridge tables) |
| Lab 4 | `PowerBI4.pbix` | Advanced modeling & relationships |
| Lab 5 | `PowerBI5.pbix` | Visuals & interactive elements |
| Lab 6 | `PowerBI6.pbix` | Dashboard layout practice |

---

### ✨ Skills Demonstrated

- Data loading and Power Query basics
- Star Schema design
- Creating relationships (1:* and *:* with bridge tables)
- Dimension tables vs Fact tables
- HR Analytics data model structure
- Sales data model structure
- Foundation for DAX and interactive dashboards

### 🚀 How to Open

1. Download any `.pbix` file
2. Open it in **Power BI Desktop**
3. Go to **Model view** to explore relationships
4. Switch to Report view to see current visuals

> Power BI Desktop is free from Microsoft Store.
